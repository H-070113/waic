# 心

一个无需安装依赖、可直接打开的私人游乐园夜游网站。

## 使用

直接打开 `index.html`。页面包含：

- 低饱和夜景中的 WebGL 上帝视角整园地图
- 六座持续运转的三维设施模型，可拖动旋转、滚轮缩放
- 城市天气同步，可定位当前位置或搜索城市
- 实时天气会改变园区的雨、雪、雾和云层氛围
- 桌面端左侧显示运行中的设施模型，右侧编辑项目简述
- 乐园名称、欢迎语自定义（默认「心」／「心之所向」）
- 汇总所有简述的园长手记

所有文字使用浏览器 `localStorage` 保存，只留在当前浏览器中；若当前环境禁用存储（例如嵌在沙箱预览框里），改动会退而写入页面地址的 `#park=` 片段。

园区背景已改为纯三维场景，不再叠加航拍照片；其余参考图的来源记录见 `assets/credits.json`。
